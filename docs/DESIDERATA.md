# Delbert - Desiderata

Nice-to-have items, not committed to the initial scope.

- Built-in PKI replacing the OpenSSL fallback (if the fallback is adopted first)
- Dynamic groups based on hardware/network attributes
- Four-eyes approval workflow for policy changes
- Agent self-update with staged rollout and rollback
- Compliance reports mapped to NIS2 art. 21 measures
- Prometheus/OpenTelemetry metrics for Core, Proxy and agents
- CBOR/COSE wire format as a compact alternative to JSON/JWS
- macOS agent
